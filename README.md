# Smart Campus System

A full-stack web application developed to streamline and digitalize campus operations by providing a centralized platform
for students, faculty, and administrators. The system enhances communication, automates academic management tasks, and
improves overall campus efficiency through a secure and user-friendly interface.

---

## Overview

The Smart Campus System is designed to simplify various institutional activities such as student management, attendance
monitoring, course handling, announcements, and event coordination.
The project focuses on creating a scalable and responsive solution suitable for modern educational institutions.

---

## Key Features

- Secure User Authentication and Authorization
- Student, Faculty, and Admin Dashboards
- Attendance Management System
- Course and Subject Management
- Campus Notices and Announcements
- Event Scheduling and Management
- Responsive and User-Friendly Interface
- Database Integration for Data Management
- Real-Time Data Handling

## Installation and Setup

### Clone the Repository

```bash
git clone https://github.com/Cctarun123/smart-campus-system.git
```

### Navigate to the Project Directory

```bash
cd smart-campus-system
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file in the root directory and add the following:

```env
PORT=5000
MONGO_URI=your_database_connection_string
JWT_SECRET=your_secret_key
```

### Run the Application

```bash
npm start
```
